Hand Coding: Multi-user Interaction

An interactive logic experiment using ml5.js handPose and Websockets for real-time collaboration.

01. Concept

This project investigates how computer vision can facilitate collaborative digital play. I developed an interactive canvas where users can "unlock" content by coordinating their physical hand movements in a shared virtual space.

02. Technical Implementation

Using ml5.js (handPose), I implemented logic to detect the coordinates of index finger tips. The system calculates the distance between users' fingers to trigger events.

// Tracking index fingers from multiple users
let d = dist(user1.indexX, user1.indexY, user2.indexX, user2.indexY);

if (d < 30) {
    gameState = 'unlocked';
    triggerAnimation();
}

03. Networking with Websockets

To enable the multi-user experience, I built a server-side architecture using Socket.io. This ensures that hand position data is synced across all clients with minimal latency, allowing for smooth, real-time interaction.
