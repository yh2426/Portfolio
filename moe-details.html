Metaverse for Education

Development Log: Bridging Physical and Virtual MakerSpaces on Quest 3.

Phase: Development in Progress

01. Research & Objectives

This research group within the NYU VIP program aims to develop immersive educational environments using metaverse platforms and mixed reality technologies. Our goal is to create learning spaces that replicate university labs, specifically the MakerSpace, accessible via devices like the Meta Quest 3.

Short-Term Goals

  • Develop a virtual reality environment of MakerSpace using the Unity Engine.
  • Integrate sensing technologies to track physical workspace dynamics.
  • Explore AI-driven object recognition for interactive machine tutorials.

02. Technical Documentation & Troubleshooting

As a member of the AR Subgroup, my focus is on the Mixed Reality pipeline. I encountered significant technical hurdles due to rapidly evolving SDKs, which required a deep dive into official migration guides.

The Challenge: Outdated SDK Prefabs During development, I found that the WebCamTextureManager prefab, which many tutorials relied on, was missing from the latest project files. It had been deprecated in favor of newer passthrough workflows, leading to undefined path errors.
The Solution: SDK Migration I successfully migrated the project to the PassthroughCameraAccess workflow by following official Meta documentation. Additionally, I moved my deployment process to the Meta Quest Developer Hub, which proved far more stable for real-time debugging than Unity's default Build & Run process.

03. Current Status & Reflections

This project is currently in progress. Due to the time required to resolve complex compatibility issues and SDK name changes (such as Unity Sentis being renamed to Inference Engine), the development has focused on stabilizing the core pipeline.

The experience has been pivotal in my growth as a developer, allowing me to transition from a Java background into C# scripting and Unity's component-based architecture. I am now fully comfortable with the development workflow and aim to complete the full independent implementation in the upcoming term.
