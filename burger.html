Burger Interaction Lab

Creative coding experiment focusing on dynamic UI and physics-based interaction.

01. Concept

This project explores playful interaction design through the simulation of a digital "burger" building experience. Using p5.js, I focused on how object states and user input can create a satisfying tactile feel in a 2D environment.

02. Technical Logic

The project utilizes object-oriented programming to manage different burger ingredients as individual classes. Collision detection and gravity-based physics were implemented to give the ingredients a sense of weight and response when stacked.
